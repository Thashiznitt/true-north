# Future Features Roadmap

This document outlines the visionary expansion of the True North ecosystem, focusing on deep integration with the Apple ecosystem to enhance accessibility, communal connection, and mindfulness.

## 💬 iMessage: Shared Sacred Spaces
iMessage integration transforms True North from a private sanctuary into a communal experience, facilitating connection within existing social circles.

### 1. Sacred Sticker Pack
- Custom-designed stickers featuring sacred geometry, liturgical symbols, and "Blessings".
- Users can annotate messages to encourage fellow seekers in their daily journey.

### 2. Interactive Invitations
- "Rich Card" previews for Sanctuary Circle invites sent via iMessage.
- Allow friends to see the circle’s belief system and join directly from the chat.

### 3. Collaborative Gratitude
- Dedicated iMessage extension for group "Gratitude Threads".
- Synchronizes group contributions into shared Circle Reflections within the main app.

### 4. Nur Snippets
- Specialized layout for sharing wisdom, scripture, or event recommendations from **Nur** (Spiritual Intelligence).

---

## ⌚ Apple Watch: The Wrist-Worn Companion
The Apple Watch companion app focuses on the "micro-moments" of spiritual alignment throughout the day.

### 1. Spiritual Complications
- **The Growth Ring**: A watch face ring tracking daily goals (Reflection, Devotion, Gratitude, Community).
- **Word of the Day**: A complication serving brief daily wisdom or affirmations.
- **Next Event**: Real-time countdown to the next ticketed Sanctuary event.

### 2. Voice-to-Spirit Journaling
- Instant dictation for "Flash Reflections" from the wrist.
- Automatic synchronization with Nur for summarization and expansion in the main app.

### 3. Haptic Mindfulness
- Gentle "Breathing" haptics for guided meditation or prayer reminders.
- Paces liturgical rhythms through subtle wrist-worn tactile feedback.

### 4. Wrist Tickets
- Automatic surfacing of QR check-in codes when approaching a physical Sanctuary event.
- Seamless, phone-free entry for events.

---

## 🛠 Technical Implementation Path
1. **Extension Targets**: Add WatchOS and iMessage Extension targets using `expo-config-plugins`.
2. **SwiftUI Interface**: Leverage SwiftUI for high-performance, native-feel extensions.
3. **Unified Storage (App Groups)**: Configure shared storage to maintain session-unlock state and user preferences across the ecosystem.
